# Submission readiness

See the [current course criteria evidence map](submission/submission-checklist.md). The course currently lists 12 criteria, including a maximum of one point for alerting. Supervised recovery does not by itself establish that an agent wakes on an alert and fixes the issue. Scores are decided by peer reviewers.

The course requires three peer reviews and a submission via the course platform. Verify the deployed app and the final requirements before submitting.
